<h1 align="center">HomiKey</h1>

<p align="center">
  اصلاح متنی که با زبان اشتباه کیبورد تایپ شده، فارسی ↔ انگلیسی، با یک کلید میان‌بر.<br>
  <a href="README.md">English</a> ·
  <a href="https://github.com/amir2139/HomiKey/releases/latest">دانلود</a> ·
  <a href="https://amir2139.github.io/HomiKey/">نسخهٔ وب</a>
</p>

شروع به تایپ می‌کنید، سرتان را بالا می‌آورید و می‌بینید کیبورد روی زبان دیگر بوده:

| چیزی که تایپ شد | چیزی که می‌خواستید |
|---|---|
| `sghl o,fd?` | `سلام خوبی؟` |
| `اثممخ` | `hello` |

متن را انتخاب کنید، <kbd>Ctrl+Shift+Space</kbd> را بزنید و HomiKey آن را طوری بازنویسی می‌کند که انگار از اول زبان درست روشن بوده.

## امکانات

- **یک کلید، در هر برنامه‌ای.** متن انتخاب‌شده را در Notepad، Word، مرورگرها، پیام‌رسان‌ها و هر برنامه‌ای که کپی و چسباندن دارد تبدیل می‌کند. کلید پیش‌فرض <kbd>Ctrl+Shift+Space</kbd> است و قابل تغییر است.
- **تشخیص خودکار جهت.** HomiKey نگاه می‌کند بیشتر متن با کدام خط است و خودش انگلیسی ← فارسی یا فارسی ← انگلیسی را انتخاب می‌کند. در متن مخلوط فقط بخش اشتباه عوض می‌شود.
- **فشار دوباره برای برگرداندن.** اگر تا ۳۰ ثانیه بعد دوباره کلید را بزنید، دقیقاً همان متن قبلی برمی‌گردد.
- **آخرین کلمه.** اگر چیزی انتخاب نشده باشد، کلمه‌ای که همین الان تایپ کرده‌اید درست می‌شود. یک کلید جداگانه هم برای آخرین کلمه هست (پیش‌فرض <kbd>Pause</kbd>).
- **چیدمان‌های فارسی.** چیدمان استاندارد فارسی (ISIRI 9147)، چیدمان قدیمی ویندوز و US QWERTY، همراه با کلیدهای Shift، نیم‌فاصله، ارقام فارسی ۰ تا ۹ و علامت‌های ، ؛ ؟ « ». HomiKey خودش تشخیص می‌دهد کدام چیدمان فارسی روی ویندوز شما نصب است.
- **عوض کردن زبان ورودی (اختیاری).** می‌تواند بعد از تبدیل، زبان ورودی ویندوز را هم به زبان متن جدید ببرد.
- **کلیپ‌بورد شما دست نمی‌خورد.** HomiKey محتوای کلیپ‌بورد را نگه می‌دارد، لحظه‌ای از آن استفاده می‌کند و بعد برش می‌گرداند. متن موقت آن در تاریخچهٔ کلیپ‌بورد ویندوز (<kbd>Win+V</kbd>) ثبت نمی‌شود.
- **فهرست برنامه‌های مستثنا.** می‌توانید HomiKey را در برنامه‌هایی که نمی‌خواهید خاموش کنید. ترمینال‌ها و برنامه‌های مدیریت رمز به‌طور پیش‌فرض مستثنا هستند، چون در آن‌ها <kbd>Ctrl+C</kbd> معنای دیگری دارد.
- **رابط فارسی و انگلیسی.** کاملاً ترجمه شده و بدون بستن برنامه قابل تغییر است. به‌طور پیش‌فرض از زبان نمایش ویندوز پیروی می‌کند. رابط فارسی راست‌به‌چپ است و از قلم وزیرمتن استفاده می‌کند.
- **برنامهٔ کنار ساعت.** هیچ پنجره‌ای جلوی کارتان را نمی‌گیرد و می‌تواند با ورود به ویندوز اجرا شود.
- **حریم خصوصی.** بدون ارسال آمار، بدون بررسی به‌روزرسانی و بدون هیچ ارتباط شبکه‌ای.
- **نسخهٔ وب.** همین مبدل در مرورگر هم کار می‌کند: <https://amir2139.github.io/HomiKey/>، برای گوشی، مک و لینوکس.

## نصب

۱. فایل `HomiKey-<version>-win-x64.exe` را از [آخرین نسخه](https://github.com/amir2139/HomiKey/releases/latest) دانلود کنید.<br>
۲. آن را در جای ثابتی بگذارید، مثلاً `C:\Users\<you>\Apps\HomiKey.exe`.<br>
۳. اجرایش کنید. آیکون HomiKey در ناحیهٔ اعلان‌ها کنار ساعت ظاهر می‌شود.

برنامهٔ نصب ندارد. فایل exe مستقل است و به نصب چیز دیگری نیاز ندارد. روی ویندوز ۱۰ و ۱۱ نسخهٔ ۶۴ بیتی اجرا می‌شود.

فایل امضای دیجیتال ندارد، برای همین ممکن است Windows SmartScreen بار اول هشدار بدهد. روی **More info** و بعد **Run anyway** بزنید. می‌توانید فایل دانلودشده را با فایل `.sha256` کنار آن در صفحهٔ انتشار مقایسه کنید.

## استفاده

| این کار را بکنید | این نتیجه را می‌گیرید |
|---|---|
| متن را انتخاب کنید و <kbd>Ctrl+Shift+Space</kbd> را بزنید | متن انتخاب‌شده تبدیل می‌شود |
| دوباره <kbd>Ctrl+Shift+Space</kbd> را بزنید | متن اصلی برمی‌گردد |
| بدون انتخاب، <kbd>Ctrl+Shift+Space</kbd> را بزنید | آخرین کلمهٔ تایپ‌شده تبدیل می‌شود |
| <kbd>Pause</kbd> را بزنید | آخرین کلمهٔ تایپ‌شده تبدیل می‌شود |
| روی آیکون کنار ساعت دوبار کلیک کنید | تنظیمات |
| روی آیکون کنار ساعت راست‌کلیک کنید | روشن/خاموش، زبان، اجرای خودکار، خروج |

در **تنظیمات** می‌توانید هر دو کلید میان‌بر را عوض کنید (روی کادر کلیک کنید و ترکیب جدید را بزنید)، چیدمان فارسی خود را انتخاب کنید، تبدیل اعداد و عوض شدن زبان ورودی را روشن یا خاموش کنید، فهرست برنامه‌های مستثنا را ویرایش کنید و تبدیل را همان‌جا امتحان کنید.

تنظیمات در `%APPDATA%\HomiKey\settings.json` ذخیره می‌شود.

## چیدمان‌های پشتیبانی‌شده

| چیدمان | نام در ویندوز | نکته |
|---|---|---|
| US QWERTY | English (United States), US | طرف انگلیسی |
| ISIRI 9147 | Persian (Standard) | «پ» روی M، نیم‌فاصله روی Shift+B (و Shift+Space) |
| قدیمی | Persian | «پ» روی `\`، «ئ» روی M، «ريال» روی Shift+R |

در تبدیل فارسی ← انگلیسی، حروفی که فقط روی چیدمان فارسی دیگر هستند هم شناخته می‌شوند.

## ساختن از روی کد منبع

به [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) نیاز دارید. خود برنامه فقط روی ویندوز اجرا می‌شود، ولی کتابخانهٔ تبدیل و تست‌هایش روی هر سیستمی ساخته می‌شوند.

<div dir="ltr">

```powershell
git clone https://github.com/amir2139/HomiKey.git
cd HomiKey
dotnet test                                   # Core tests
dotnet run --project src/HomiKey.App          # run the tray app (Windows)

# The same single-file exe the release workflow builds:
dotnet publish src/HomiKey.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

</div>

نسخهٔ وب فقط HTML، CSS و JavaScript ساده در پوشهٔ [`web/`](web) است. آن را با هر سرور فایل ایستا باز کنید، مثلاً `npx serve web`. تستش: `node web/test.mjs`.

### ساختار پروژه

<div dir="ltr">

```
src/HomiKey.Core/         conversion library (no Windows dependencies)
src/HomiKey.App/          WinForms tray app
  Resources/Strings*.resx all interface text (English, Persian)
  Assets/                 icons, Vazirmatn font
tests/HomiKey.Core.Tests/ xUnit tests
tests/vectors.json        conversion cases shared by the C# and web tests
```

### انتشار نسخه

با push کردن یک تگ مثل `v1.0.0`، گردش‌کار انتشار اجرا می‌شود: تست‌ها را اجرا می‌کند، فایل exe تک‌فایلی و مستقل `win-x64` را می‌سازد و آن را همراه SHA-256 به یک GitHub Release جدید پیوست می‌کند. نسخهٔ وب هم هر بار که `web/` روی شاخهٔ `main` تغییر کند روی GitHub Pages منتشر می‌شود (اول در تنظیمات مخزن، Pages را با منبع «GitHub Actions» فعال کنید).

## پرسش‌های رایج

**با زدن کلید هیچ اتفاقی نمی‌افتد.**
مطمئن شوید آیکون آبی (فعال) است و برنامه در فهرست مستثناها نیست. اگر برنامهٔ دیگری کلید میان‌بر را گرفته باشد، HomiKey هنگام اجرا خبر می‌دهد؛ در تنظیمات کلید دیگری انتخاب کنید. ویندوز اجازه نمی‌دهد برنامه‌های معمولی به برنامه‌هایی که با دسترسی Administrator اجرا شده‌اند کلید بفرستند، پس HomiKey در آن‌ها کار نمی‌کند مگر این‌که خودش هم با همان دسترسی اجرا شود.

**حروف اشتباه درمی‌آیند.**
در تنظیمات، گزینهٔ «چیدمان کیبورد فارسی من» را بررسی کنید. HomiKey بار اول آن را از چیدمان‌های نصب‌شده حدس می‌زند. چیدمان خود را در Settings ویندوز ← Time & language ← Language & region ← Persian ← Language options ببینید.

**چرا HomiKey از کلیپ‌بورد استفاده می‌کند؟**
کپی و چسباندن تنها راهی است که در تقریباً همهٔ برنامه‌های ویندوز برای خواندن و جایگزین کردن متن انتخاب‌شده کار می‌کند. HomiKey محتوای قبلی کلیپ‌بورد را نگه می‌دارد و بلافاصله بعد از چسباندن برش می‌گرداند، و متن موقت خودش را طوری علامت می‌زند که در تاریخچهٔ کلیپ‌بورد ثبت نشود.

**چرا ترمینال مستثناست؟**
در ترمینال، <kbd>Ctrl+C</kbd> بدون انتخاب، برنامهٔ در حال اجرا را متوقف می‌کند. اگر در ترمینال فقط روی متن انتخاب‌شده از HomiKey استفاده می‌کنید، می‌توانید آن را از فهرست حذف کنید.

**در VS Code (یا Visual Studio) بدون انتخاب، یک خط کامل تکرار می‌شود.**
این ویرایشگرها با <kbd>Ctrl+C</kbd> بدون انتخاب، کل خط را کپی می‌کنند. یا اول متن را انتخاب کنید، یا این رفتار را خاموش کنید (در VS Code: `"editor.emptySelectionClipboard": false`).

**تبدیل آخرین کلمه در Word قالب‌بندی را از بین برد.**
برای درست کردن آخرین کلمه، HomiKey از مکان‌نما تا ابتدای خط را انتخاب می‌کند و همان بخش را فقط با تغییر آخرین کلمه دوباره می‌چسباند. این روش در متن راست‌به‌چپ و چپ‌به‌راست یکسان کار می‌کند، ولی در ویرایشگرهای پیشرفته آن بخش به‌صورت متن ساده چسبانده می‌شود. برای حفظ قالب‌بندی، اول کلمه را انتخاب کنید.

**آنتی‌ویروس به آن گیر می‌دهد.**
برنامه‌هایی که برای برنامه‌های دیگر کلید می‌فرستند گاهی مشکوک شناخته می‌شوند. HomiKey فقط <kbd>Ctrl+C</kbd>، <kbd>Ctrl+V</kbd> و <kbd>Shift+Home</kbd> را می‌فرستد، آن هم فقط وقتی کلید میان‌برش را بزنید. کد منبع همین‌جاست و می‌توانید exe را خودتان بسازید.

**آیا چیزهایی را که تایپ می‌کنم ثبت می‌کند؟**
نه. HomiKey هیچ قلاب کیبوردی (keyboard hook) ندارد. فقط وقتی کلید میان‌بر را بزنید متن را می‌خواند، فقط به اندازهٔ تبدیل آن را در حافظه نگه می‌دارد و هیچ چیزی را به هیچ جا نمی‌فرستد.

**چطور حذفش کنم؟**
تیک «اجرا هنگام ورود به ویندوز» را بردارید، از منوی آیکون گزینهٔ خروج را بزنید و بعد فایل exe و پوشهٔ `%APPDATA%\HomiKey` را پاک کنید.

**مک یا لینوکس؟**
از [نسخهٔ وب](https://amir2139.github.io/HomiKey/) استفاده کنید.
